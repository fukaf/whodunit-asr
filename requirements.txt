# Core runtime. Pinned to the versions verified against the code in this repo.

# Python 3.11 or 3.12 is required: whisperx caps at <3.14 and pyannote.audio 4.x
# requires >=3.11. Do NOT use 3.13 - torch 2.8 wheels exist but the
# ctranslate2 / torchcodec matrix is not reliable there yet.
#
# --- GPU install (do this FIRST, before the line below) --------------------
# Plain `pip install torch` from PyPI gives a **CPU-only** wheel on Windows.
# For NVIDIA GPUs install torch from the CUDA index instead:
#
#   pip install --index-url https://download.pytorch.org/whl/cu128 \
#       torch==2.8.0+cu128 torchaudio==2.8.0+cu128
#
# cu128 is required for Blackwell (RTX 50xx / B100 / B200, sm_100/120).
# Older cu121 wheels install cleanly and then report no CUDA devices.
# Verify with:  python -c "import torch; print(torch.cuda.is_available())"
# If pip overwrites it on a later install, re-run the command above.
# ---------------------------------------------------------------------------
